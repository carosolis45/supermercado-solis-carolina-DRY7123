# Supermercado Inventory - Solis Carolina

🔗 **Enlace al repositorio:** [https://github.com/carosolis45/supermercado-solis-carolina-DRY7123](https://github.com/carosolis45/supermercado-solis-carolina-DRY7123)

Este es un proyecto desarrollado para la asignatura **Frontend II** (Sigla: DRY7123).

## Descripción
Sitio web de gestión de inventario para un supermercado desarrollado con React. Incluye navegación con **React Router**, **Estado Global** (Context API) para manejar el inventario en tiempo real, un formulario para ingresar productos y una tabla para visualizarlos, todo estilizado con el framework **Tailwind CSS** en modo oscuro.

## Vistas del sitio
* **Home (/)**: Panel principal con el catálogo de productos, búsqueda y estadísticas de stock dinámicas.
* **Inventario (/inventario)**: Tabla que muestra los artículos agregados al sistema.
* **Agregar (/agregar)**: Formulario para ingresar nuevos artículos (nombre, marca, tipo, precio y stock).
* **Quiénes Somos (/quienes-somos)**: Información de la empresa, misión, visión y valores.
* **Contáctanos (/contactanos)**: Formulario de contacto e información de la tienda.

## Tecnologías utilizadas
* React
* React Router DOM
* Context API (Estado Global)
* Tailwind CSS
* Vite

## Instalación y ejecución
1. Clonar el repositorio.
2. Instalar las dependencias con `npm install`.
3. Ejecutar el servidor local con `npm run dev`.
4. Abrir el navegador en `http://localhost:5173/`.
