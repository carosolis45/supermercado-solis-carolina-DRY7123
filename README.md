# Supermercado Inventory - Solis Carolina

**Sitio web en vivo (GitHub Pages):** [https://carosolis45.github.io/supermercado-solis-carolina-DRY7123/](https://carosolis45.github.io/supermercado-solis-carolina-DRY7123/)

**Enlace al repositorio:** [https://github.com/carosolis45/supermercado-solis-carolina-DRY7123](https://github.com/carosolis45/supermercado-solis-carolina-DRY7123)

Este es un proyecto desarrollado para la asignatura **Frontend II** (Sigla: DRY7123).

## Descripción
Sitio web de gestión de inventario y carrito de compras para un supermercado, desarrollado con React. Incluye navegación con React Router, Estado Global (Context API) para manejar el inventario y el carrito en tiempo real, un formulario para ingresar productos, una tabla con filtros y una pantalla de detalle con carrito funcional. Todo estilizado con **Tailwind CSS** en modo oscuro.

## Vistas del sitio
* **Home (/)**: Catálogo de productos con búsqueda y estadísticas dinámicas.
* **Inventario (/inventario)**: Tabla de artículos con **filtro por categoría**.
* **Agregar (/agregar)**: Formulario para ingresar nuevos artículos.
* **Detalle (/producto/:id)**: Información del producto, selección de cantidad y opción de agregar al carrito.
* **Carrito (/carrito)**: Lista de productos seleccionados, modificación de cantidades y cálculo de total.
* **Quiénes Somos (/quienes-somos)** y **Contáctanos (/contactanos)**.

## Tecnologías utilizadas
* React
* React Router DOM (HashRouter)
* Context API (Estado Global)
* Tailwind CSS
* Vite
* GitHub Pages (Despliegue)

## Instalación y ejecución
1. Clonar el repositorio.
2. Instalar las dependencias con `npm install`.
3. Ejecutar el servidor local con `npm run dev`.
4. Abrir el navegador en `http://localhost:5173/`.
